# The design mockup

`emr-console.html` is the vanilla HTML/CSS/JS prototype the current redesign was
built from — the seven-module rail, the sub-theme meters, the banded tables and
the Investment Plan were all drawn here first and wired into React afterwards.

It is kept because it is the only artefact that shows the *intended* design
whole. The React app is the design plus a year of wiring compromises; when the
two disagree, this file is the argument for what was meant.

Its own banner states the terms:

> DESIGN MOCKUP · REAL ASSESSMENT NUMBERS · TABLE FILTERS AND THE FACILITY
> PICKER WORK; CHARTS DO NOT RECOMPUTE

So: the figures are real, lifted from `public/data/`. The interactivity is
partial — enough to judge a layout, not enough to trust as a second
implementation. It is not a spec and it was never validated against the ETL.

## Running it

It is fully self-contained: no external hosts, no `fetch`, data inlined. Opening
it directly works.

```bash
open docs/mockup/emr-console.html
```

**It will not render through `npm run dev`.** Vite injects its HMR preamble into
any HTML it serves, which terminates the mockup's inline scripts early and dumps
the rest of the JS onto the page as text. `vite preview` serves flat static files
and does not, so if you need it on an HTTP origin rather than `file://`:

```bash
cp -r docs/mockup public/mockup && npm run build && npm run preview
```

Then open `/mockup/emr-console.html` on the preview port. Delete `public/mockup`
afterwards — anything under `public/` is copied into `dist/` and would ship to
Netlify.

## How it is built

Three Python scripts, run in this order. Each writes its output next to itself,
so run them from inside this folder.

| Script | Reads | Writes |
|---|---|---|
| `geo.py` | `public/geo/nigeria-states.geojson`, `nigeria-lgas.geojson` | `geo-states.json`, `geo-lgas.json` |
| `data.py` | `public/data/*.json`, `geo-*.json` | `data.js` |
| `build.py` | `part-css.css`, `data.js`, `part-js.js` | `emr-console.html` |

`geo.py` projects both boundary files into one shared SVG frame — equirectangular,
scaled to a 1000-unit width, with Douglas–Peucker simplification and a bbox-area
filter that drops islands and digitising slivers. LGA paths are emitted only for
the 12 primary states.

`data.py` flattens the ETL output into a compact `window.EMR` object with
single-letter keys (`n` count, `d` archetype distribution, `ts` theme scores).
That terseness is why `data.js` is 355KB rather than several megabytes; it is
generated, so read `data.py` rather than the JSON.

`build.py` is a concatenation — CSS into a `<style>`, data and behaviour into two
`<script>`s, no head or body. That shape matters: the file has no `<!doctype>`,
`<html>` or `<body>` wrapper by design.

**Both `.py` files hardcode an absolute path** to
`/Users/solomonpromise/Documents/Synterra Github Repos/emr-dashboard/public/`.
They are preserved verbatim, as the record of what actually produced the
committed HTML. Edit the constant at the top of each before re-running them
anywhere else.

Regenerating needs Python 3 only — no packages.

## Files

| File | |
|---|---|
| `emr-console.html` | The mockup. Generated by `build.py`; committed because it is the runnable thing. |
| `part-css.css` · `part-js.js` | Hand-written source. **Edit these**, then re-run `build.py`. |
| `data.js` · `geo-states.json` · `geo-lgas.json` | Generated. Do not hand-edit. |
| `build.py` · `data.py` · `geo.py` | The pipeline above. |
| `readiness-ledger.html` | An earlier, discarded iteration, kept for the record. Superseded — do not build on it. |

Committing generated output alongside its source is the same call `public/data/`
makes, for the same reason: nothing in CI can regenerate it, since the ETL's
inputs are not in the repository.

## Known divergences from the shipped app

Where the React app and this file disagree and the mockup is right:

- **Overview lead sentence.** The mockup reads "Change readiness, digital
  familiarity and routine data use are the three highest-scoring sub-themes."
  `src/modules/home/HomePage.tsx` interpolates the labels straight into the
  sentence head, losing the capital and the conjunction: "change readiness,
  routine data use, digital familiarity are the highest-scoring…".
